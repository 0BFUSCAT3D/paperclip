# Context

Phase 7 (PAP-16897) built a package-local model of a native Paperclip run:
a generated capability contract (7A), a UX interaction map (7B), a deterministic
mock `ControlPlanePort` (7C), a transport-neutral semantic tool catalog and
authorization engine (7D, security gate 7D/PAP-16902, remediation PAP-16909),
an eval-derived 106-case conformance suite (7E), and a read-only browser
scenario explorer (7F, UX gate PAP-16905). Phase 7G (PAP-16906) produces the
reference documentation, the clean-start tutorial, the evidence manifest, and
this OKF entry. It was blocked until 7E and 7F were done because the tutorial
and evidence must describe and exercise the final conformance and browser
surfaces.

# Decisions

1. Keep the reference set flat under `docs/phase-07-*.md`, matching the existing
   per-phase reference convention, rather than introducing a new folder. Eight
   reference pages: capability disposition, mock control plane, semantic tools,
   authorization/exposure, eval conformance, scenario explorer, future binding
   boundary, and verification commands.
2. Treat the hand-written capability-disposition page as a reader's guide to the
   generated `docs/phase-07-capability-contract.md`; never restate the generated
   table, which carries a "DO NOT EDIT" header and is rewritten by
   `generate:phase7-inventory`.
3. Write the tutorial to run from the repository root with two commands to first
   success, no Rust toolchain, no Paperclip service, and no external eval
   repository. State time-to-first-success and exact expected output.
4. Make the verification evidence file the single manifest: a command→result
   matrix, artifact links, and the security/UX/QA gate issues. Capture real
   observed output rather than asserting expected output.
5. Do not commit the generated parity report. It is an on-demand artifact; a
   clean checkout does not contain it, and the tracked
   `evidence/phase-07/index.md` already documents it as generated.
6. Update `docs/index.md`, `docs/architecture.md`, `README.md`, and the two
   knowledge indexes additively. Keep ACPX as Phase 8 and state that real
   Paperclip integration requires separate approval.
